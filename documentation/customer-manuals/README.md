# RestaurantOS — Customer Manuals Directory & Distribution Index

Welcome to the official documentation package for **RestaurantOS Enterprise F&B Operating System** (v1.4.0+).

This directory contains customer-ready manuals designed for restaurant owners, general managers, billing operators, kitchen chefs, and service staff.

## 3. Printing & Mobile Guidelines

- **For Counter/Laminated Printouts:** All PDFs are formatted according to international A4 dimensions (`210mm x 297mm`) with generous 45pt margins and vector typography suitable for full-color or black-and-white laser printing.
- **For Smartphone & Tablet Viewing:** Documents utilize responsive single-column layouts with clear section dividers, high-contrast typography, and bulleted callouts for easy reading on 6-inch mobile screens and 10-inch tablets.
- **Language Support:** All documents are written in clear, jargon-free English and structured modularly for future regional localization (Hindi and Bengali).
